## How to contribute

- Open an issue before making a large change.
- Keep changes focused and easy to review.
- Write clear commit messages.
- Add or update tests when relevant.
- Follow the repository coding style.

# install dependencies here

## Development workflow

1. Create a feature branch.
2. Make your change.
3. Run relevant checks or tests.
4. Submit a pull request with a summary and validation steps.

## Pull request guidelines

- Keep PRs small and focused.
- Explain the reason for the change.
- Include screenshots or examples when they help.
- Reference related issues when applicable.

## Code of conduct

Please be respectful and constructive in all discussions and contributions.
