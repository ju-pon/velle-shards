# Security Policy

## Supported versions

The project maintainers will support the latest version and current release branch unless otherwise noted.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues or discussions.

Instead, contact the maintainers privately using the preferred security contact method for the project.

Please include:

- a concise description of the vulnerability
- affected version or commit
- steps to reproduce
- potential impact
- any suggested mitigation

We aim to acknowledge valid reports promptly and work toward a fix as quickly as possible.

## Disclosure policy

We ask that reporters allow a reasonable timeframe for a fix before making details public, so that users can be protected and a coordinated response can be made.
